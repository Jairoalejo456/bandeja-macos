# Identidad de MiniTray

`MiniTrayLogo.png` es el logotipo maestro elegido por el propietario del proyecto.
El catálogo `AppIcon` conserva la composición y los colores originales, con un
encuadre optimizado para que el símbolo resulte legible en los tamaños usados por
macOS.

La barra de menús utiliza una adaptación monocromática de bandeja porque macOS
renderiza esos símbolos como imágenes de plantilla y el logotipo completo perdería
legibilidad a 16 puntos.
